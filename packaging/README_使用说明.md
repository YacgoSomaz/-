# 复盘虾

## 安装

1. 解压整个文件夹，不要只复制单个 exe。
2. 双击 `安装到桌面.bat`。
3. 安装完成后，桌面会出现 `复盘虾` 快捷方式。

重复安装会更新程序文件，并保留已经添加的直播号、录音、导出结果和数据库。

## 使用

1. 双击桌面快捷方式。
2. 等待浏览器自动打开 `http://127.0.0.1:8848`。
3. 添加抖音直播号。
4. 点击开始监听。
5. 导出 Excel 后，在 `exports` 目录查看结果。

如果不想安装，也可以直接双击文件夹里的 `LiveWatchLauncher.exe` 临时启动。

## 数据位置

安装后数据默认在：

`%LOCALAPPDATA%\LiveWatch`

常用目录：

- `app/audio/<直播号>/`：每个直播间的录音，按 `1.mp3 / 2.mp3 ...` 命名。
- `app/exports/`：导出的 Excel、Markdown 和汇总表。
- `app/transcripts.db`：话术转写数据库。
- `app/multi_events.db`：弹幕/进场/点赞/直播数据数据库。

## 注意

- 关闭启动器黑窗口会停止监听。
- 首次遇到抖音验证码时，程序可能会弹出浏览器窗口，请手动完成验证。
- 不建议一开始就高并发，先从 1-3 个直播间测试。
- 安装包已自带 Node 运行时；Windows 默认 Edge 浏览器通常即可完成验证码弹窗。
