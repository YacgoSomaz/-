# 直播复盘侠 · 使用说明

## 启动
双击桌面或开始菜单的 **直播复盘侠**，程序会打开独立客户端窗口，不需要使用浏览器。

点击窗口右上角关闭按钮后，直播复盘侠会缩到系统托盘并继续监听。需要重新打开时，双击托盘图标；
需要彻底停止监听时，右键托盘图标并选择「彻底退出」。

## 首次使用：铸 Cookie
抖音对非浏览器会话有验证墙。第一次监听某房间时，会自动弹出一次 Edge 浏览器窗口完成验证
（一闪而过属正常）。若取流失败，到控制台点「重新验证 Cookie」即可。

## 你的数据存在哪
程序文件和你的数据是**分开**的：

| 类型 | 位置 |
|------|------|
| 程序、模型 | 安装目录（默认 `%LOCALAPPDATA%\\Programs\\LiveWatch`） |
| Cookie、房间清单、数据库、录音、导出、日志 | `%LOCALAPPDATA%\\LiveWatch\\data` |

在文件资源管理器地址栏输入 `%LOCALAPPDATA%\LiveWatch\data` 回车即可打开数据目录。

## 升级
直接运行新版安装程序覆盖安装即可，**你的数据不会被动**（数据在上面的独立目录里，安装/卸载都不碰）。

## 卸载
卸载时默认**保留**你的数据。如果想连数据一起清掉，卸载程序里会有「同时删除全部用户数据」的明确选项。

## 离线
安装包自带 Node、FFmpeg、SenseVoice 语音识别模型和 3D-Speaker 声纹模型，安装后即可离线运行。
（仅"铸 Cookie"这一步需要联网过抖音验证墙，属正常。）
