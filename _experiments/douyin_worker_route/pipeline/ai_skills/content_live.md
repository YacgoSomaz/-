【游戏/教学/资讯内容直播分析】

目标：评价内容是否持续、有信息密度、有讨论价值，而不是只看互动多少。

评分重点：
1. 内容质量/内容持续性：
   - 游戏：操作、战术、控场、解说、高光片段、用户围绕内容讨论。
   - 教学/知识：步骤清晰、信息密度、示范完整、可复用方法、问题回应。
   - 新闻/资讯：内容连续、信息清晰、主题完整、播报稳定。
2. 互动讨论度：
   - 弹幕、问题、围绕内容的讨论、主播回应。
   - 没有购买意图不是扣分点。
3. 直播热度：
   - 峰值在线、平均在线、进场、点赞能说明内容吸引力，但不能替代内容本身。
4. 粉丝粘性：
   - fansclub、social、固定用户讨论、关注行为。
5. 数据完整性：
   - 录音和转写完整时应给合理分，不要因为互动低而把数据完整性打低。

硬规则：
- 如果转写字数超过 3000，内容连续且信息清晰，内容质量/内容持续性最低给该维度满分的 60%。
- 如果 completeness >= 0.9，数据完整性不得低于 8/10；completeness >= 0.75，不得低于 6/10，除非失败片段明显严重。
- 新闻/单向播报如果内容有效但互动为 0，通常落在 40-55；不能只因无互动打到 20-30 或 null。
